📌 In one sentence:Sky Scan runs entirely on your device. It does not collect, upload, or store any of your personal data.

1. 数据处理原则

Sky Scan 是一款浏览器扩展，所有功能完全在用户的浏览器中本地运行。我们采用"本地优先"原则：

  • ✅ 不搭建任何后端服务器
  • ✅ 不收集任何个人信息
  • ✅ 不使用分析、埋点、追踪 SDK
  • ✅ 不向任何第三方服务发送数据
  • ✅ 不在浏览器外存储数据

2. 权限说明

扩展声明的每个权限都仅用于完成核心功能，无任何隐藏用途：

权限用途是否传输数据
activeTab仅在用户主动点击扩展图标时，访问当前激活标签页的 DOM 用于检测表格/文章否
scripting将检测与采集函数注入当前标签页执行否
downloads触发浏览器原生下载，将 CSV / JSON / DOCX 文件保存到用户的下载目录否
storage在 popup 会话之间临时保存已采集数据，仅存于浏览器本地否
tabs查询当前激活标签页的 URL 与标题（不读取历史）否
<all_urls>允许在任意域名工作（企业内网 / SaaS 后台 / 自定义域名），因为 Sky Scan 是通用采集工具否

3. 关于登录态

Sky Scan 不请求、不存储、不读取任何账号密码。当你在已登录的网站（如后台管理系统）使用本扩展时：

  • 扩展只读取页面上已渲染的 DOM 元素（表格单元格、文章正文）
  • 不会主动发起任何 HTTP 请求复用你的 cookie
  • 不会修改页面请求头或注入任何脚本到外部域名
  • 所有数据流向：网页 → 浏览器内存 → 用户主动下载的文件

4. 数据存储位置

4.1 浏览器本地存储（chrome.storage.local）

采集过程中的临时数据保存在 chrome.storage.local，该存储：

  • 仅存于本机浏览器配置文件中
  • 不与 Chrome 账号同步（与 storage.sync 不同）
  • 用户可在 chrome://extensions → Sky Scan → "清除存储数据" 一键清除
  • 卸载扩展时自动清除

4.2 用户下载的文件

导出的 CSV / JSON / DOCX 文件由用户主动触发下载，保存位置由浏览器下载设置决定（默认为"下载"文件夹）。这些文件归用户所有，扩展不再访问。

1. Data Processing Principles

Sky Scan is a browser extension that runs entirely on the user's device. We follow a "local-first" principle:

  • ✅ No backend server of any kind
  • ✅ No personal information collected
  • ✅ No analytics, tracking, or telemetry SDKs
  • ✅ No data sent to any third-party service
  • ✅ No data stored outside the browser

2. Permission Justifications

Every permission declared by the extension is used solely for its core functionality:

PermissionPurposeTransmits Data?
activeTabAccess the current active tab's DOM only when the user clicks the extension icon, to detect tables/articlesNo
scriptingInject detection and scraping functions into the active tabNo
downloadsTrigger native browser downloads to save CSV / JSON / DOCX files to the user's downloads folderNo
storageTemporarily persist collected data between popup sessions, local onlyNo
tabsQuery the current active tab's URL and title (no history access)No
<all_urls>Allow scraping on any domain (enterprise intranets, SaaS dashboards, custom subdomains), since Sky Scan is a universal scraping toolNo

3. About Login State

Sky Scan does not request, store, or read any account credentials. When you use the extension on a logged-in website:

  • The extension only reads DOM elements already rendered on the page (table cells, article body)
  • It does not initiate any HTTP requests to reuse your cookies
  • It does not modify page request headers or inject scripts into external domains
  • Data flow: webpage → browser memory → user-initiated download file

4. Data Storage Locations

4.1 Browser Local Storage (chrome.storage.local)

Temporary data during scraping is saved in chrome.storage.local, which:

  • Exists only in the local browser profile
  • Does NOT sync with your Chrome account (unlike storage.sync)
  • Can be cleared via chrome://extensions → Sky Scan → "Clear storage data"
  • Is automatically cleared when the extension is uninstalled

4.2 User-Downloaded Files

Exported CSV / JSON / DOCX files are downloaded on user-initiated action. The save location is determined by your browser's download settings (default: "Downloads" folder). These files belong to the user; the extension does not access them afterward.

  • ❌ Do not collect your browsing history

  • ❌ Do not read or upload cookies
  • ❌ Do not install tracking pixels or analytics
  • ❌ Do not share data with any ad network
  • ❌ Do not read files outside your browser
  • ❌ Do not request microphone / camera / location permissions

7. Children's Privacy

Sky Scan is not directed at children under 13, and we do not knowingly collect information from any age group.
